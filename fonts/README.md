# Fonts

Subset (Latin) copies of **Instrument Sans** (Regular, Bold) and **Instrument Serif** (Regular, Italic),
converted to WOFF2 so the game works fully offline. Both families are licensed under the SIL Open Font
License 1.1 (see `OFL-InstrumentSans.txt`; Instrument Serif is released under the same license by the same foundry).
